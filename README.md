# AIFMS Creator Cognitive Profile Tool
A free web-based tool by AI Finally Makes Sense.

Paste your AI session output and receive a personalized, branded 
Creator Cognitive Profile report you can download as a PDF.

## Built For
Creators, solopreneurs, and AI curious beginners who want to 
understand how their brain works and what to build from it.

## How To Use
1. Run the Session Observer or Memory Reader prompt in Claude or ChatGPT
2. Copy the full response
3. Paste it into this tool
4. Download your branded PDF report
